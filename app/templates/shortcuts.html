用 iPhone 快捷指令发送

设置一次以后，在“照片”或任何 App 里点“分享 → 发送到电脑”，不用先打开 CrossSync 网页。下面的地址和令牌已经替你填好，照着在 iPhone 的“快捷指令”App 里建两个快捷指令即可。

先记下这两项

电脑地址
{{ base_url }}
授权头
Bearer ••••••••••••

令牌相当于密码，不要截图分享。第一次用快捷指令发送时，电脑上会弹出“iPhone 快捷指令 想连接这台电脑”，点“允许”后再运行一次。

快捷指令一：发送照片和文件

  1. 打开“快捷指令”App，点右上角“+”新建，名字改成“发送到电脑”。
  2. 点底部的 ⓘ，打开“在共享表单中显示”，接受的类型选“图像”“媒体”“文件”。
  3. 添加操作“对每个项目重复”，输入选“快捷指令输入”。
  4. 在循环里添加“获取 URL 内容”，URL 填： {{ base_url }}/api/upload-stream?target=downloads 点“显示更多”：方法选 POST；头部添加一项，键填 Authorization，值填上面的授权头；请求体选“文件”，文件选“重复项目”。
  5. 可选：在 URL 末尾加上 &name= 再插入变量“重复项目 → 名称”，电脑上就会保留原来的文件名（不加的话按时间命名）。
  6. 循环后面可以加“显示通知”，内容写“已发送到电脑”。

快捷指令二：把剪贴板发到电脑

  1. 新建快捷指令，名字改成“剪贴板发到电脑”。
  2. 添加操作“获取剪贴板”。
  3. 添加“获取 URL 内容”，URL 填： {{ base_url }}/api/text 方法选 POST；头部同上；请求体选“JSON”，添加一个“文本”类型的键 text，值选“剪贴板”。
  4. 电脑上运行着 CrossSync 托盘程序时，文字会直接进入电脑剪贴板，直接粘贴即可。也可以在 CrossSync 的“文字”页看到。

也可以把它加到“控制中心”或“轻点背面”，一按就发。
